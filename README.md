# ModemResetter PRO 🌐

Программа на Python с графическим интерфейсом (GUI) для автоматического аппаратного перезапуска USB-модемов и Wi-Fi адаптеров при зависании сети.

## ⚡ Какую проблему решает?
При высокой нагрузке (например, скачивании больших файлов через торрент) некоторые USB-модемы зависают: Windows показывает, что сеть есть, но интернет пропадает. Помогает только физическое извлечение модема из порта. 
Этот скрипт автоматизирует процесс, имитируя «переподключение» устройства на уровне операционной системы без участия пользователя.

## ✨ Особенности и функции
- **Удобный интерфейс**: Написан на Tkinter, не требует работы через консоль.
- **Два режима работы**: 
  - `Ручной перезапуск` — мгновенный сброс устройства по нажатию кнопки.
  - `Авто-режим` — циклический перезапуск устройства каждые 5 минут в фоновом режиме.
- **Безопасность**: Скрипт использует асинхронные таймеры `window.after` вместо жестких циклов `while`, благодаря чему интерфейс программы никогда не зависает.
- **Защита системы**: Встроенный модуль `ctypes` проверяет права Администратора при старте программы, предотвращая системные сбои Windows.

## 🛠️ Технологии
- **Python 3**
- **Tkinter** (для создания GUI)
- **Subprocess & Pnputil** (для глубокого управления устройствами Windows)
- **Git** (контроль версий)
